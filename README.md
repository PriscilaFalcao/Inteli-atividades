# Repositório de atividades

Este repositório tem o objetivo de armazenar as atividades desenvolvidas durante o período de faculdade. Contam com pequenos projetos, desenvolvidos para a entrega de atividades ponderadas. Nenhum deles integram um sistema real, as informações são todas fictícias e a infraestrutura e arquitetura não seguem as melhores práticas do mercado, tendo em vista que possuem o objetivo de aprendizado.
